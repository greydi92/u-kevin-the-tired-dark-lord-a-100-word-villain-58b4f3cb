# The Tired Dark Lord: A 100-Word Villain Monologue

A program that writes one ~100-word monologue to `/output/entry.txt` — a fantasy
villain, three hundred years into ruling the Ashen Marches, rescheduling the
apocalypse because the ravens haven't been fed yet.

Bounty: https://make.fun/bounty/u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb

## Run

```sh
node main.ts
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`). No network,
no input files, exits 0.

## Entry

100 words, 566 characters — a dark lord mid-ritual, interrupted by mundane
exhaustion: cold floors, unfed ravens, a proclamation in triplicate, and a
crown somebody else will have to carry up the stairs.
